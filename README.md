# RMUC 2026 分区赛战术数据可视化

本项目是一个面向 RMUC 2026 分区赛数据的战术复盘网页。它把区域赛过程数据、总决赛参赛手册队伍名单和规则手册场地图结合起来，用于观察队伍收益结构、对局强度、场地控制和机器人开局行动。

## 项目内容

网页包含八个主要视图：

- **总览**：展示队伍数量、对局数量、最高平均伤害队伍、对抗强度 Top40、队伍画像和开局布置总览。
- **队伍画像**：比较晋级手册队伍的火力收益、科技核心装配收益和飞镖收益。
- **比赛预测**：合并赛程模拟概率、上赛季国赛成绩参考和队伍风格聚类，展示复活赛晋级、全国赛阶段概率和风格分布。
- **南工骁鹰**：单独聚合哈尔滨工业大学（深圳）南工骁鹰战队的收益结构、预测概率、地图控制、开局站位、对局复盘、胜负原因和逐局指标。
- **专题分析**：集中展示科技核心和地图控制。
- **对局地图**：展示红蓝双方均为全国赛或复活赛手册队伍的全量对局，每场包含热力图和代表局轨迹图。
- **开局布置**：按英雄、工程、步兵、哨兵、空中等兵种拆分，展示开局 0-30 秒平均站位。
- **数据入口**：提供项目使用的 CSV 数据表和指标说明文档。

## 数据范围

当前版本覆盖：

- 已命名手册队伍：44 支
- 双方均为全国赛或复活赛手册队伍的对局：96 场
- 对局局数：234 局
- 对局地图：每场 2 张图，分别为全场热力图和代表局轨迹图

队伍范围来自总决赛参赛手册中已命名的全国赛与复活赛队伍。对局范围仅保留红蓝双方都属于这些队伍的区域赛对局。

## 核心图表

### 队伍战术收益画像

队伍画像使用三类指标描述队伍收益结构：

- **平均造成伤害**：每局平均造成的非判罚伤害，反映正面对抗、集火和持续输出能力。
- **平均装配次数 x1400**：科技核心装配次数的显示缩放值，反映工程与经济滚雪球能力。
- **平均飞镖伤害 x8**：飞镖命中伤害的显示缩放值，反映飞镖系统对建筑目标的贡献。

`x1400` 和 `x8` 只是为了让不同量级的指标能在同一张图中比较，不代表规则意义上的等价换算。

### 官方场地图对局分析

对局地图使用规则手册中的战场俯视图作为底图：

- 热力图合并该场全部局，显示红蓝双方机器人活动密度。
- 轨迹图选取该场总非判罚伤害最高的一局作为代表局。
- 数据坐标按 28m x 15m 战场范围线性映射到底图。

这类图适合观察区域控制、行动路线和战术重心，不适合用于厘米级定位判断。

### 开局兵种布置

开局布置统计每个队伍-局-兵种在 0-30 秒内的平均位置，并按兵种拆分：

- 英雄
- 工程
- 步兵3
- 步兵4
- 哨兵
- 空中

图中红/蓝表示阵营，圆点表示该局胜方，叉号表示该局负方。

### 专题分析

专题分析页将当前保留的派生指标整理为可切换模块：

- **科技核心/工程**：统计装配次数、等级装配、首次装配时间和相关收益。
- **地图控制区域**：以学校为第一层筛选，排除空中机器人后，展示每个兵种活动占比最高的场地区域，并映射到规则手册场地图上。

### 比赛预测

比赛预测页合并两类模型输出：

- **赛程模拟预测**：按参赛手册中的复活赛、全国赛瑞士轮和淘汰赛设计，使用 70% 当前区域赛模型与 30% 上赛季国赛成绩参考分，模拟复活赛晋级全国赛概率，以及各队全国赛十六强、八强、四强和夺冠概率。
- **队伍风格聚类**：基于火力、装配、飞镖和低易伤暴露对队伍做风格分类，并与阶段概率合并展示。

### 南工骁鹰专栏

南工骁鹰专栏将同一支队伍的多张数据表合并展示：

- **队伍画像**：火力、装配、飞镖、风格低暴露分和综合模型强度。
- **比赛预测**：十六强、八强、四强和冠军概率。
- **地图控制**：各兵种最高活动区域映射到官方场地图。
- **开局站位**：0-30 秒开局坐标均值和样本量。
- **对局复盘**：已分析对局结果、伤害净值和图集跳转。
- **胜负原因**：对比胜局与败局的输出、受伤、装配、金币、基地血量和易伤暴露差异。
- **逐局指标**：逐局伤害、装配、易伤、金币和末基地血量。

## 指标口径

- **伤害**：来自 `events` 表中的 `受击` 事件。事件值为负扣血，分析时取相反数；`判罚` 类伤害不计入非判罚输出。
- **装配**：来自 `装配成功` 事件，按队伍和局统计。
- **飞镖**：来自 `飞镖命中` 事件，统计命中造成的伤害。
- **易伤**：来自逐秒状态表的 `是否易伤` 字段，以机器人秒累计。
- **金币**：来自逐秒状态表的队伍金币字段，同一秒内按队伍去重后使用。

## 说明

本项目用于战术复盘和数据浏览，不作为官方赛果、官方排名或规则裁定依据。分析结果依赖当前数据库字段和可提取事件，未覆盖现场故障、检录状态、临场策略调整和人工判罚细节等因素。
